## Contact Memory & Autocomplete

### What
Introduces an **Organization-scoped Contact Directory & Memory Engine** that remembers procurement contacts per client organization and auto-suggests them when adding tender extensions or creating/editing tenders.

### Why
Procurement contact details (name, email, phone) frequently repeat for the same client organization (e.g., City of Tshwane, Eskom). Previously, users had to retype the same contact information every time. This feature eliminates that friction by automatically remembering contacts and providing autocomplete suggestions.

### How It Works

1. **Automatic Memory**: Every time a contact is used in a Tender or Extension, the system silently saves/upserts them into the `client_contact` database table for that client.
2. **Autocomplete**: When typing in the "Contact Person Name" field (in Extension or Tender forms), a dropdown appears with matching historical contacts for the selected client.
3. **Auto-populate**: Selecting a suggestion instantly fills **Name**, **Email**, and **Phone** fields.
4. **Seamless New Contacts**: If typing a contact that doesn't exist yet, it acts as a normal text input and is saved on form submission.
